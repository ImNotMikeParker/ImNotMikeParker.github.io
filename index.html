Agent-driven build loop

Claude Code is the primary development workflow across production .NET and Blazor repositories. Planning, implementation, test coverage, and pull requests are executed through the agent rather than alongside it.

Custom agent tooling

Subagents, skills, hooks, and repository-level conventions that encode architecture rules, coding standards, and review checklists, so agent output conforms to the codebase instead of requiring rework.

Cross-model adversarial review

Codex acts as an independent reviewer of Claude-generated changes before merge, surfacing regressions, edge cases, and faulty assumptions that single-model self-review consistently misses.

MCP tool integration

MCP servers and custom tooling wired into the agent loop give agents direct access to databases, APIs, and internal systems, so changes are made against real context rather than inference.
